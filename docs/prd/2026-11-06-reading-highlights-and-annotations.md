# 阅读重点与批注 PRD

需求日期：2026-11-06
状态：已确认的产品设计；交互细节见文末。

本文定义阅读模式中重点、文字批注和 Apple Pencil 的产品行为。通用视觉、布局和动效遵循[设计规范](../../design/README.md)，实现职责以[架构设计](../native-architecture.md)为准。

## 目标

用户在阅读 Markdown 时，可以直接划线、针对文字写批注，并继续正常滚动、选择和复制。操作围绕正文就地完成，保持阅读界面简洁。

面向 iPhone 和 iPad 的阅读模式，支持手指、鼠标、触控板，以及适用设备上的 Apple Pencil。重点与批注分别创建和删除，可以同时存在，数据独立于 Markdown 原文持久保存。

## 术语与状态

| 术语 | 含义 |
| --- | --- |
| 重点 | 内部用于描述正文波浪下划线的概念；用户界面使用“划线”“移除划线” |
| 批注 | 用户针对关联文字填写的说明，可以独立存在 |
| 关联范围 | 重点或批注对应的正文文字范围 |

| 状态 | 正文呈现 | 轻点后的交互 |
| --- | --- | --- |
| 只有重点 | 波浪线 | 原生菜单提供“添加批注…”“移除划线” |
| 只有批注 | 关联文字的浅色背景高亮和批注图标 | 直接展示批注内容，可编辑，并提供“划线”“删除批注…” |
| 重点与批注共存 | 波浪线、浅色背景高亮和批注图标 | 点关联文字区域或图标，打开同一份批注内容；可编辑，并提供“移除划线”“删除批注…” |

批注关联的文字平时以很浅的底色提示范围。打开该批注时略微加强高亮，关闭后恢复浅色。系统选字时使用系统选区样式。

波浪线与文字底部保留清晰间距，正文、代码和表格使用一致的视觉关系，随字号适配。

批注图标是位于关联文字末尾的小型辅助标记，随正文排版预留空间，避免遮挡后续文字。关联文字是主要点击入口，图标保持轻巧；具体尺寸与间距通过原型确认。

## 创建与状态变化

| 用户操作 | 结果 |
| --- | --- |
| 选中文字，在系统菜单中选择“划线” | 生成波浪线，完成后继续阅读 |
| 选中文字，选择“添加批注…”并填写完成 | 创建文字批注，关联文字显示浅色背景高亮和批注图标 |
| 轻点已有重点，选择“添加批注…”并填写完成 | 保留重点，新增文字批注 |
| 在已有批注面板中选择“划线” | 保留批注，给相同关联范围添加波浪线 |
| 用 Pencil 在文字下方划动 | 识别为划线后，逐步显示对应文字的波浪线，抬笔完成 |

新增批注以填写并完成为建立条件。取消时保留操作前的状态，包括已有重点。

纯划线在重叠或首尾相接时合并为一条，包含前后半句分别划线的情况；中间仍有未划文字时分开。Markdown 的强调、行内代码等语法符号不形成显示文字之间的间隔。合并后的划线作为同一对象移除或添加批注。带有文字批注的记录保持各自范围和内容，不参与纯划线合并。

## 支持的正文内容

正文、行内代码、代码块和表格中的文字均支持划线与批注，通过系统文字选择菜单操作。

代码保留等宽排版和语法高亮。表格保持原有结构，波浪线和批注背景对应实际选中的文字。跨行代码或跨单元格的选区，按各处实际选中的文字显示，使用同一份批注内容。

## 点击、选择与复制

### 点击范围

重点的点击区域是被划线的文字区域，包括下方波浪线。批注的关联文字区域和批注图标均为点击入口。重点与批注共存时，这些入口打开同一份批注内容。

重点或批注跨行时，每一行中对应的文字都可以点击打开。同一行其余文字按普通正文操作。

### 系统选择与复制

| 操作 | 预期行为 |
| --- | --- |
| 轻点已有重点或批注的关联文字 | 按当前状态打开重点菜单或批注内容 |
| 长按、双击选词 | 进入系统文字选择菜单，保留复制等系统操作和现有“在 AI 对话中引用…”入口，并提供“划线”“添加批注…” |
| 拖动选区手柄、使用鼠标或触控板拖选 | 调整实际选区，维持系统选择状态 |
| 在系统选区菜单中主动选择动作 | 对实际选区执行划线、添加批注或现有 AI 引用操作 |

例如，一句话已有重点和批注：点一下查看批注；长按或双击其中的文字是为了选字；拖动手柄是为了调整范围。长按、双击和拖选过程中，系统选择手势优先；批注面板只响应独立的轻点。

自定义动作加入现有系统选择菜单，保留原有操作和快捷键。链接点击继续保留原有含义，链接与重点、批注重叠时的具体入口需专项确认。

正文复制只包含实际选中的文档内容；批注窗口内的复制只包含该处选中的批注文字。编辑批注时沿用原生剪切、复制、粘贴和键盘快捷键。例如，整句话有重点，用户只选中三个字，复制结果只包含这三个字，原重点与批注保持原样。

## Apple Pencil

### 直接划线

在文字下方落笔并沿该行划动，如同在纸上画下划线；识别范围允许笔划稍微接触文字底部。手划轨迹接受直线和波浪线，最终统一显示对齐文字的规整波浪下划线。识别为划线后即时显示波浪线，抬笔完成并留在阅读界面。每次划线保存对应文字范围，根据当前排版绘制波浪线。拿起笔和悬停时保持当前界面。

Pencil 点击控件、链接和已有重点或批注时，完成对应点击。批注输入区域使用原生文本输入，支持系统“随手写”。手指继续保留正文滚动与系统选择操作。

### Pencil 滚动与划线判定

Pencil 支持正文上下滚动，以及表格、代码块等已有可横向滚动内容的左右滚动。落笔时检查文字下方的起笔区域，再以随文字尺度变化的空间容差判断方向，允许波浪笔势起步时的小幅上下起伏。

| 笔势 | 响应 |
| --- | --- |
| 在正文区域主要上下拖动 | 滚动正文 |
| 在可横向滚动的表格、代码块等内容中主要左右拖动 | 横向滚动该内容 |
| 靠近某行文字下方、主要沿该行划动 | 划线 |
| 轻点 | 执行对应点击 |

同一次笔势确定用途后，保持该用途至抬笔。已识别的划线可以继续上下起伏，落笔区域不持续限制整条笔画。可横向溢出的内容内优先滚动；方向容错与命中范围是共享交互参数，结合真实 Pencil 核对略斜的下划线、斜向滚动和手掌接触。

## 原生菜单与批注面板

只有重点时使用两项系统菜单。有批注时直接展示内容。

根据内容、字号与键盘出现后的可用空间，使用锚定正文的原生 popover 或系统 sheet，两种呈现承载同一个批注窗口。具体适配分界见待确认事项。

| 打开方式 | 内容与输入状态 |
| --- | --- |
| 新建批注 | 打开空白批注正文区域，直接显示光标并进入输入 |
| 打开已有批注 | 展示已有文字，轻点正文即可继续输入；打开时保持键盘收起 |

查看、新建和编辑始终使用同一个批注窗口，字体、底色、间距、文字区域和按钮布局保持一致。窗口上方提供“取消”“完成”，文字区域始终具备原生选择与输入能力，轻点正文后即可书写。已有批注提供“划线”或“移除划线”，以及“删除批注…”操作。

popover 打开时确定关联文字中的锚点及相对位置。查看期间随正文一体滚动，保持与该锚点的距离及上下关系；滚动不触发换边、切换关联行或重新播放入场动效。窗口尺寸、排版或键盘改变可用空间时调整布局，保留打开时的上下关系。

查看批注时，popover 随正文自然滚出视口。浮层连同箭头及可见阴影完全离开视口后，才在屏幕外清除打开状态，不播放退场动效。仅关联文字离开视口时，仍可见的浮层继续保持。滚回原处保持关闭，用户重新点击关联文字后打开。

文字内容保持原样时，点击外部可以关闭。文字有修改时，通过“完成”保存或“取消”恢复打开时的文字，意外点到外部或滚动正文时保留编辑现场。新建取消保留创建前的状态。空内容及异常中断的细节列入待确认项。

批注内容优先，使用系统语义字体、颜色和原生圆角外观；操作只呈现当前状态相关的动作。短内容自然收紧，长内容在受可用空间限制的区域内滚动。滚动条在文字区右侧单独留出间距，正文左右留白保持协调。输入界面避让系统键盘和局部输入浮条。

呈现与关闭沿用系统转场。键盘出现时，同一窗口连续调整布局；单次编辑期间保持呈现方式稳定，文字增长通过输入区滚动容纳。适应 Reduce Motion、快速操作和窗口变化，Pencil 书写期间保持输入区域稳定。

## 移除划线与删除批注

两种操作各自确认，只处理对应的重点或批注。

| 操作 | 确认标题 | 按钮 | 结果 |
| --- | --- | --- | --- |
| 移除划线 | 移除划线？ | 取消／移除 | 去掉波浪线；已有批注、背景高亮和图标保留 |
| 删除批注 | 删除批注？ | 取消／删除 | 去掉批注文字、背景高亮和图标；已有波浪线保留 |

使用系统模态确认弹窗与破坏性动作样式。取消保持原状；移除唯一存在的重点或删除唯一存在的批注后，恢复普通正文。主动删除操作以确认弹窗防止误删，源码编辑沿用原有撤销／重做。

## App 内正文变化后的处理

重点与批注保存关联文字的起止位置。App 内编辑时，根据实际编辑的位置与文字增删更新这些位置，手动源码编辑与 AI 文档编辑遵循相同行为。

| 正文变化 | 重点与批注的处理 |
| --- | --- |
| 在关联范围之外增删内容 | 更新对应位置 |
| 修改或删除部分关联文字 | 更新范围；仍有对应文字时继续保留 |
| 关联文字全部删除或整体替换 | 对应重点与批注一起移除 |
| 剪切后粘贴到其他位置 | 原位置按删除规则处理，粘贴后的内容视为普通正文 |
| 撤销／重做正文编辑 | 同步恢复／重做该次正文编辑引起的重点与批注变化 |
| 旋转、分屏、窗口变化或正文重新排版 | 根据关联文字重新定位和绘制 |

正文撤销／重做只同步对应编辑带来的变化，保留用户后续主动删除重点、删除批注或编辑批注的结果。

## 保存与生命周期

重点与批注在本机离线持久保存，Markdown 原文保持原样。以规范化后的完整文件路径关联数据，路径包括文件夹和文件名，每条记录保存关联文字的起止位置。主动关闭文档、重启 App 或清除最近打开记录后，重点与批注仍然保留。

| 文件操作 | 数据关联 |
| --- | --- |
| 重新打开相同路径 | 读取该路径的重点与批注记录，按已保存的位置显示 |
| 同名文件位于不同路径 | 分别保存各自的记录 |
| 用另一份文件替换相同路径的文件 | 读取该路径已有的重点与批注记录，沿用已保存的位置 |
| 文件移动或重命名后从新路径打开 | 按新路径保存和读取记录 |

## 验证要求

- 三种状态可分别创建，并按规定相互转换；移除划线时保留批注，删除批注时保留重点，取消确认保持原状态。
- 批注关联文字的浅色背景随面板开关加强、恢复；系统选字时使用系统选区样式。
- 文字区域和对应图标可点击，跨行触控与相邻内容的原有操作保持一致。
- 已有重点或批注的正文仍可长按、双击、拖选、调整手柄和复制；选择操作按实际选区执行。
- 代码和表格的文字支持划线与批注；跨行、跨单元格范围对应实际选中的文字。Pencil 可上下滚动正文、左右滚动表格和代码块。
- 新建、查看和编辑共用同一窗口、文字区域和按钮布局；新建直接输入，已有批注轻点正文继续输入。取消与完成保持正确内容，系统复制、粘贴、输入法候选和 Pencil 随手写正常。
- 查看时批注与关联文字一体滚动，来回及快速滚动保持相对位置；浮层及阴影仍有部分可见时继续保留，全部离开视口后无可见退场。滚回原处不自动打开，未提交的输入保持完整。
- 本机重开、进程恢复、保存、App 内正文编辑及撤销／重做保持重点和批注的一致性，各文档的数据归属正确。
- 同名不同路径分别关联数据；相同路径替换文件后沿用该路径的记录；移动或重命名后按新路径处理。
- 两端模拟器验证面板、菜单、选择复制和布局；Pencil 命中、滚动、手掌接触与实际书写由真实设备验证。
- 验证旋转、分屏、大字号、深色外观、Reduce Motion、系统输入浮条，以及长文中密集或相邻范围。
