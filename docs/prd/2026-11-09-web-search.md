# AI 联网搜索与网页阅读

需求日期：2026-11-09。适用于 iPhone 与 iPad 的预览和源码模式。

## 使用方式

用户在模型设置中配置自己的搜索服务与 API Key。App 直接向所选服务发送搜索词或需要读取的网页地址，取得资料后交给当前模型继续回答。

搜索默认关闭。配置完成后，AI 根据本轮要求按需搜索，用于查找最新资料、核实外部信息或执行用户明确的搜索要求。回答中的来源使用可点击的 Markdown 链接。

未配置或关闭时，不注册搜索工具，普通文档对话沿用现有行为。产品能力说明可以介绍可选搜索，实际执行以本轮工具列表为准。用户明确要求联网时，AI 简短说明当前未启用搜索并引导现有模型设置，仍可依据已有资料回应。配置保存成功后，后续提问自动取得工具。

## 模型设置

在模型连接信息之后增加“联网搜索”分组：

| 字段 | 行为 |
| --- | --- |
| 搜索服务 | 关闭、Serper、Tavily、Brave Search |
| API Key | 选择服务后显示原生安全输入框；每个服务分别保存密钥，切换时恢复相应值 |

搜索设置与模型设置一起提交或取消。启用搜索时必须填写对应密钥，字段校验失败使用原生错误弹窗，保留草稿。“重置”清除完整连接信息及所有搜索密钥。关闭搜索保留已填写密钥，便于重新启用。

连接信息仅保存在本机钥匙串，Web 渲染层与模型消息不接收密钥。界面使用现有表单、语义颜色与本地化规范。

## 首次使用授权

向一个搜索服务首次发起请求前，使用原生确认弹窗展示服务名称、本次实际搜索词或网页地址，以及结果将提供给当前 AI 服务的说明。支持正文读取的服务同时说明会发送选定网页地址，并将提取正文提供给模型。提供“取消／允许”。允许后在本机记住该服务；切换到另一服务重新确认。

取消本次授权时不发送搜索请求。本轮后续调用保持这一选择，AI 可以根据已有资料继续回应。停止生成、关闭文档、切换文档或渲染进程退出时，关闭待处理确认并取消关联请求。

## 搜索结果与对话

统一工具返回查询、检索时间，以及来源标题、URL、摘要和服务提供的发布日期。一次请求取得一页最多十条结果；模型可以根据任务继续提出不同查询。

搜索词与结果保留在该轮工具执行记录中，供追问、恢复与重试使用。同一轮重复的相同调用复用已有结果，避免重复付费请求；重复且没有进展时沿用现有循环保护。用户在新一轮要求重新查询时取得新结果。

搜索结果是外部资料，不能改变用户指令、读取范围或编辑权限。预览保持只读；源码模式仍仅在用户明确要求时编辑当前文档。模型应区分结果摘要与网页原文，使用实际返回的来源支持事实。

## 网页正文

提供 `web_search` 查找来源，提供 `read_webpage` 按需读取正文。网页阅读可直接使用搜索结果、文档或用户给出的链接；模型根据问题决定是否需要进一步阅读。

| 服务 | 搜索 | 正文读取 |
| --- | --- | --- |
| Serper | Google 搜索结果 | 同一枚 Key，返回提取的纯文本 |
| Tavily | 搜索结果 | 同一枚 Key，返回提取的 Markdown |
| Brave Search | Web 搜索结果 | 按当前适配接口提供摘要 |

正文保留来源、标题、提取时间和格式，长页面按完整 Unicode 字符位置分页，也可查找指定文字。返回内容明确标记读取范围、总字符数及下一段位置，完整提取内容与本次返回片段分开表达。同一轮对同一 URL 的分页和查找复用已取得的正文；后续追问保留实际读过的片段，并纳入现有上下文整理。

提取请求只发至固定服务端点，由所选服务读取网页；模型和 Web 渲染层都不接收搜索密钥。网页内容是外部资料，引用实际来源；无法取得正文时如实说明。

## 失败与取消

鉴权、额度或限流、网络中断、超时、无结果与无效响应分别处理。服务失败作为工具结果返回模型，回答如实说明取得资料的情况。停止生成取消进行中的搜索。搜索服务、模型及协议都由用户配置确定。

## 验证

两端验证配置保存、取消、重置、服务间密钥隔离、首次授权与拒绝、有效及空结果、错误处理、取消、正文分页与查找、来源链接、多轮引用、进程恢复与重复调用。真实服务联调使用独立测试凭据，与离线回归分开执行。
