# 界面与交互设计规范

本文规定 MarkdownIt 当前界面的视觉层级、布局、组件行为与动效，面向设计和实现维护者。模块关系、数据流及文件访问边界见[架构设计](../docs/native-architecture.md)。

阅读划线与批注的产品需求见[PRD](../docs/prd/2026-11-06-reading-highlights-and-annotations.md)。

## 设计原则

- 正文是阅读界面的主体。操作按需呈现，收起的面板释放正文空间。
- 采用系统控件、语义颜色、原生材质和系统选择菜单，保持触控、指针与键盘操作的一致性。
- 同一内容共用渲染能力，同一操作共用组件；布局变化不改变操作含义。
- 文案说明当前对象、状态或后果。保留必要标签与无障碍名称，避免欢迎语、预设提问和重复提示。

## 视觉基础

| 要素 | 规范 |
| --- | --- |
| 品牌 | 首页标志与系统 App 图标由同一矢量母版和配色生成。首页保留图形原色；系统图标的外形由系统处理。制作方法见[品牌资源](brand/README.md)。 |
| 字体 | 原生界面使用系统语义文本样式。首页 slogan 使用离线打包的 Newsreader Regular，按 Title 2 缩放；整句保持同一字体、字重和颜色。源码和代码使用等宽字体。 |
| 颜色 | 原生容器使用系统背景、标签、分隔线与强调色；Web 正文接收原生解析后的语义颜色。选中、标记、语法和修改差异使用各自的语义色。 |
| 材质 | 阅读页悬浮控件使用圆形、可交互的系统 Liquid Glass，按压、指针和聚焦反馈保持同一外形。 |
| 对齐 | 同一组控件共享中心线、尺寸和有效触控范围。对话正文与输入区共享左右边界；引用标记、首行和移除动作对齐。 |
| 可访问性 | 图标操作保留可访问名称。文字适应系统大字号，内容允许换行和滚动；反馈同时通过文字或控件状态表达。 |

尺寸、间距、颜色和动效参数由 [tokens.json](tokens.json) 维护。原生语义样式与 Web 的平台适配分别由原生视图和 `WebSource/native.css` 实现；系统材质不以 CSS 透明度或模糊半径模拟。

## 布局与适配

布局响应可用窗口空间。阅读操作在不同窗口宽度下保持相同的展开与收起机制；目录和 AI 面板使用同一套窗口空间规则，支持旋转、分屏和自由调整窗口。正文的最低可读宽度、辅助面板宽度与间距共同决定能否并排，不按设备名称、朝向或分屏比例判断。

| 区域 | 紧凑布局 | 空间充足时 |
| --- | --- | --- |
| 首页 | 品牌与操作纵向居中；空间不足时整组可滚动 | 保持紧凑的品牌组与操作组，周围留白弹性分配 |
| 阅读操作 | 右下角一个展开按钮，向左展开操作 | 保留相同的展开按钮与操作关系 |
| 正文目录 | 展开时覆盖正文 | 展开时与正文并排 |
| AI 对话 | 正文与 AI 无法舒适并排时使用底部面板 | 右侧面板与正文并排；iPad 竖屏在空间足够时保留此布局 |
| 最近打开 | 可调整高度的系统 sheet | 锚定入口的 popover |

辅助面板按可用宽度分为三种布局：能容纳目录、正文和 AI 时允许三栏并排；只能容纳正文与一个面板时，目录和 AI 互斥展开；两栏也放不下时，目录覆盖正文左侧，AI 从底部呈现，仍保持互斥。打开一个面板直接收起另一个，原有目录入口在 AI 打开时仍可操作。收起当前面板后回到正文，不自动恢复另一面板。

窗口收窄导致三栏无法容纳时，保留最近主动操作的辅助面板；自动目录跟随和回答流更新不改变优先级。窗口变宽后只恢复同时展开的能力，不自动重新打开已收起的面板。面板切换、旋转和窗口调整保留阅读位置、草稿、对话，以及目录分支和滚动状态。软键盘改变高度，不改变基于宽度的布局选择。转场连续衔接，并遵循 Reduce Motion。

阅读界面不设顶栏。预览和源码至少填满可用视口，长文随内容增长，旋转和分屏后按新窗口尺寸布局。目录开关位于左上方。AI 未展开时，关闭文档位于右上方；侧边 AI 展开时移至正文列左上方，收起 AI 后返回右上方。目录展开时，关闭按钮位于目录右侧的正文区域；目录收起时，与目录开关保留明显间隔，没有目录开关时占据左上角。正文顶部为关闭按钮保留空间，避免覆盖开头标题。三个顶部控件共享中心线与触控尺寸。AI 面板展开时，底部操作组淡出并退出交互与辅助功能树；面板收起完成后，以折叠状态淡入恢复。目录收起后占用宽度为零，仅开关保留有效触控范围。

阅读视口与背景延伸至屏幕底部，不以独立空白条保留底部安全区。悬浮操作与 AI 输入仍避让 Home 指示条；正文和源码的末尾留有可滚动的避让空间。

完整停靠键盘出现时，内容视口避让键盘；浮动键盘及实体键盘的局部输入浮条不缩短整页阅读容器。

底部悬浮操作可见时，通过原生键盘布局指引避让输入界面。底部输入浮条出现时，操作组整体移至其上方并保留共享间距，展开动作沿同一高度向左延伸；隐藏输入界面后恢复底部安全区内的位置。AI 面板显示期间移除操作组的定位宿主，不再为隐藏的操作组计算输入避让。系统提供动画时沿用系统时序；输入浮条分次、无动画地更新布局时，补齐连续的原生布局动画，新目标从当前可见位置衔接。靠近顶部的浮动键盘不把操作组推到屏幕之外，透明定位容器不拦截正文操作。

## 会话恢复

系统终止应用后，再次启动恢复原文档、预览或源码模式、阅读位置、选区和同一份撤销／重做历史；辅助面板按当前窗口重新布局，保留目录分支、对话和草稿。恢复期间显示中性加载状态，避免先展示首页或文首再跳转。用户主动关闭文档且保存成功，或明确放弃修改后关闭，才结束会话；取消关闭或保存失败继续保留现场。

AI 会话按文档完整路径独立保存，预览与源码共用；切换模式、收起面板、前后台切换和关闭后重开均保留，仅手动清空历史删除对话。主动关闭文档仍结束阅读现场，下次启动返回首页。会话保留原始引用与图片快照、已接收回答、工具修改记录和未发送草稿。进程被终止时的生成恢复为中断状态，由用户手动重试，不自动发起网络请求。原文件已被其他应用修改时，先通过原生提示选择保留文件内容或恢复的修改，不自动覆盖。

## 首页与最近文档

首页依次呈现标志、`just markdown, pure reading.`、横向并排的“打开文档”和“新建文档”，以及下方的“最近打开...”次级文字按钮。打开与新建复用同一原生玻璃按钮，保持同等视觉层级、宽度和高度；打开使用系统强调色，新建使用石墨色。按钮组保持紧凑宽度，两颗按钮之间的间距独立于下方次级操作的纵向间距；具体参数由设计 tokens 维护。操作组随可用空间收窄，文字适应系统字号。标志与 slogan 组成品牌组，品牌组和操作组之间使用更大的间距。两颗文档按钮作为一个操作组入场，顺序由内容集合决定。

新建文档使用系统保存窗口，先选择文件名和位置，默认位于本应用的本地文档目录。成功创建空白 Markdown 文件后直接进入源码模式，光标位于开头并可立即输入；后续保存、撤销、恢复与最近记录使用原有文档流程。取消保存窗口返回首页，创建失败使用统一错误提示。

slogan 在宽度足够时显示一行；窄布局先在逗号后的短语边界换行，大字号下允许继续自然换行。各行保持相同样式，不通过缩小文字强行容纳。

中文最近打开入口为“最近打开...”，使用三个 ASCII 点号。列表项展示文件名和父文件夹，按最近成功打开的顺序保留十个不同文档；重开已有文档将该项移到首位。空列表显示空状态，打开失败保留列表并提示错误。紧凑布局的关闭动作与标题同排；popover 可点击外部关闭。

隐私政策仅在首页底部安全区的右侧提供文字入口，使用系统 Caption 与次级颜色，触控范围不小于共享标准。其下以 Caption 2 和三级文字颜色显示发布版本与构建号，保持右对齐，仅为文本，不提供额外操作。版本来自应用的 Bundle 元数据。入口与中央品牌、操作组分开，不覆盖滚动内容。点击打开原生模态窗口，使用系统导航栏和关闭动作；正文随 App 语言选择中英文，使用原生文本、列表、表格和滚动容器，支持离线阅读、大字号和深色外观。滚动视口延伸至弹窗底部，内容通过系统安全区避让，保持圆角边界连续。

## 阅读与源码

预览正文使用正文栏的全部可用宽度，不设置固定的最大宽度。两侧保留基础内边距；正文到相邻目录或 AI 面板的可见留白保持一致，AI 面板靠屏幕外缘的间距单独计算，不重复加入正文一侧。目录、AI 面板、旋转和窗口调整改变可用空间时自然重排，字号与行距不随栏宽改变。文首及标题跳转为顶部悬浮控件保留避让空间。

预览呈现只读文档；源码显示并编辑 Markdown 原文。两种视图共享 AI、视图切换和更多操作，更多仅包含模型设置。所有窗口宽度下均保留右下角的展开／收起按钮，初始收起。选择 AI 或切换视图后收起操作组；正文点击、编辑聚焦、旋转和窗口宽度变化不改变展开状态。隐藏操作退出触控和焦点范围，其位置不拦截正文。源码额外提供撤销、重做，执行历史操作后保留操作组，不能执行的动作显示为禁用。

源码以原生 TextKit 2 全页编辑区域呈现，采用支持动态字号的系统等宽字体与自然行高。背景连续铺满视口，不使用表单边框、圆角输入框或独立的底部留白；文本内边距为关闭按钮和底部操作预留可滚动空间。软键盘和实体键盘沿用系统避让，源码中的回车始终插入换行。开始与结束输入沿用同一操作组，仅按键盘实际区域调整避让位置。

切换视图跟随当前内容：切换前视口顶部的段落或代码行，在目标视图中保持大致相同高度。目录跳转定位正文，源码与预览显示同一份文档内容。关闭文档先保存，成功后返回首页。

### 本地资源授权

本地图片缺少访问权限时，只请求实际资源所在的具体目录，不自动扩大到无关目录的共同上级。多个目录逐个处理；父目录本身也是资源所在目录时，可同时覆盖其子目录。已有且仍有效的目录授权直接复用。

点击本地 Markdown 链接时，缺少权限则请求目标文档所在的具体目录。图片和文档链接共用原生授权面板、目录校验与书签；标题和说明按用途呈现。授权成功后继续原操作：图片重新加载，文档链接自动打开目标文档。取消保留当前文档及阅读位置，再次点击链接可以重新授权。

授权仅使用一个原生模态小面板：标题使用系统标题样式，说明使用次级文字颜色，实际目录路径单独成段、使用正文颜色和中等字重，允许换行；内容过长或大字号时可滚动查看，底部保留“取消”和“选择文件夹”。紧凑窗口按内容高度从底部呈现，空间充足时居中显示。从面板直接呈现系统选择器，选择期间保留底层面板，避免先退场再进场的割裂转场。用户手动前往并选择目录。不指定选择器的起始位置。选错目录或授权失败后回到同一提示，用户可以继续选择或取消；取消后正文仍可阅读，未获授权的图片暂不加载。图片本身不存在不触发授权提示。

### 目录导航

| 操作 | 行为 |
| --- | --- |
| 滚动正文 | 按正文可见视口从顶部起约三分之一处所在的小节更新当前章节，让对应目录项在目录面板中大致居中；文档开头保留首项，末尾保留可见的最后一项，目录首尾按可滚动范围收敛 |
| 快速滚动或反向滚动 | 从目录当前的位置与速度连续跟随最新章节，不排队执行过时目标 |
| 手动浏览目录 | 暂停自动跟随；重新操作正文时恢复，开关或切换辅助面板保留手动浏览位置 |
| 点击目录项 | 跳转正文并使用当前项反馈；触控反馈与行样式保持一致 |
| 收起分支 | 以可见祖先代表当前后代，不强制展开用户收起的分支 |

展开与收起复用同一个圆形目录开关，不附加可见文字标题，保留可访问名称。目录包含原文的 H1 至 H6，文档开头的一级标题同样保留。没有可生成的目录项时隐藏开关和面板，不占正文宽度；编辑后重新生成目录时同步更新可用性。目录行共享前导触控列和单层反馈，层级仅改变文字缩进；分支展开动作与标题跳转分别响应。自动跟随只滚动目录面板。

### 划线与批注

阅读时的划线与文字批注分别保存，可以单独存在或关联同一段文字。纯划线重叠或首尾相接时合并，中间有未划文字时分开；带批注的记录保持独立。划线统一呈现为有清晰字底间距的波浪线；批注以很浅的文字背景和末尾小图标提示，打开时加强关联范围的背景。小图标随排版预留空间，文字区域是主要点击入口。

系统选择菜单保留复制与 AI 引用，并提供“划线”“添加批注…”。轻点已有划线的文字或波浪线，展示添加批注和移除划线的原生菜单；轻点批注关联文字或图标，打开批注。长按、双击和拖选继续交由系统文字选择；链接保留跳转，重叠批注可从末尾图标打开。

创建、查看和编辑复用同一原生卡片，使用纸面色、柔和边界与阅读字体。新建直接输入，已有内容打开时不唤起键盘，轻点文字即可编辑。卡片保留“取消”“完成”，已有批注提供独立的划线及删除操作；移除划线和删除批注各自使用原生破坏性确认。正文、代码与表格按实际关联文字呈现。

卡片根据锚点附近的可用空间选择就地浮层或系统 sheet。就地浮层固定初始上下关系，随正文一体滚动；包括箭头和阴影全部离开视口后，在屏外清除打开状态。键盘和重排调整同一个卡片，未提交的输入保持可见并纳入恢复现场。长内容在卡片内部滚动，文字与滚动条之间保留共享间距。

Pencil 在文字下方沿行划动时逐步显示规整波浪线，抬笔保存。起笔容差随文字尺度变化，允许小幅上下起伏；用途明确后保持到抬笔。竖向笔势滚动正文，可横向溢出的代码与表格优先保留横向滚动。手指滚动、系统选择与原生输入不切换模式。

划线和批注按完整文件路径独立保存在设备上，不改写 Markdown。App 内源码和 AI 编辑通过同一编辑历史更新关联位置，完整删除范围时移除记录；正文撤销同步恢复对应范围，但不恢复用户主动删除的记录或覆盖后来修改的批注。

## AI 对话

当前文档默认作为 AI 的背景资料，选段和图片引用进一步指明关注内容。全局 AI 入口使用当前文档，不能沿用已经放弃的选段。预览和源码的系统选择菜单都提供一个“在 AI 对话中引用…”动作，使用实际选中内容进入同一对话。界面支持多轮交流，输入区保留可访问名称，不显示输入占位语或预设问题入口。

对话采用浅冷色表面与柔和边界，深色外观保持同一层级；配色仅作用于对话面板。AI 面板的背景、按钮、输入及发送区域由同一个原生容器布局，正文的滚动与边界回弹不改变其位置。顶部使用固定的紧凑操作行，清空与收起分居两侧，中间显示本地化标题“AI 对话”／“AI Conversation”，三者垂直居中对齐；对话滚动区从其下方开始。用户提问使用轻量气泡，首条与后续提问遵循同一宽度规则；回答在共享边界内直接排版。对话滚动区仅在对应方向还有未展示内容时显示边缘渐隐，上下共用同一尺寸；到达边界或内容不足一屏时恢复完整显示。紧凑布局的拖动指示条位于标题上方，拖动区域与对话滚动区域分离。

目录与关闭文档图标使用 18pt SF Symbols 和 24pt 居中画布；AI 顶部操作使用更紧凑的 16pt SF Symbols。各图标保留原生视觉比例，触控范围均为 44pt。侧边面板的操作与关闭文档按钮共享水平中心线。面板顶部由共同对齐线及内部留白确定，底部保留安全区间距，允许上下外边距不同。

答复优先使用用户明确指定的语言，其次使用本轮提问的主要交流语言；混用多种语言时依据提问句式和意图判断。只根据本轮提问判断语言，不以文档、历史回答、代码或借用术语决定；无法判断时使用当前界面语言兜底。

预览中的 AI 辅助阅读；用户要求修改时，引导其切换到源码模式。源码中的 AI 也可解释和讨论，只有明确的修改要求才执行文档编辑。实际修改以变化卡片呈现，区分已修改、已撤销与保存失败；卡片中的撤销遵循当前历史顺序，不越过后续编辑。技术权限与执行过程见[架构设计](../docs/native-architecture.md#ai-上下文与编辑执行)。

首次向某个服务发送前，用系统确认弹窗说明全文、提问、本次对话，以及选中或模型读取的图片将发送到该服务地址，提供“取消”和“允许”。确认前不提交对话轮次；取消保留草稿与引用，不发送请求。允许后在设备上记住该服务，重启不重复询问；更换服务地址重新确认，切换模型、接口类型或更新 API Key 不重复询问。失败轮次改向另一个服务重试时同样需要确认，取消不改变已有回复。打开 AI 面板与查询模型列表不触发文档发送授权。

AI 顶部的清空与收起操作共用尺寸与对齐线，默认仅显示图标：清空使用系统破坏性色，收起使用次级文字色。指针悬停、按压或键盘聚焦时，在 44pt 触控区域内浮现 34pt 的圆形原生 Liquid Glass 底面；交互结束后淡出。反馈复用共享材质动效，支持快速反转与 Reduce Motion。没有历史时禁用清空按钮。点击后使用原生确认弹窗；确认会停止生成并清空对话、摘要及模型工具上下文，保留未发送草稿、当前引用和文档的编辑历史。取消保持原状。清空后仍留在当前面板，后续提问作为新对话发送，恢复现场同样保留清空后的状态。

模型可按需使用原生只读工具取得当前日期、时间和时区，不需要联网或额外系统授权。

### 联网搜索

模型设置提供可选的“联网搜索”分组，默认关闭。支持 Serper、Tavily、Brave Search；选择服务后显示 API Key，切换服务恢复各自的密钥。搜索与模型设置一起保存或取消，重置清除所有连接信息。两类密钥复用同一原生安全输入样式。

搜索关闭或未配置时，不提供搜索工具；能力说明仍可介绍产品支持可选搜索。普通阅读问题正常回答，明确要求联网时才说明当前未启用并引导现有模型设置。配置保存后，后续提问即可按需搜索。

首次使用一个搜索服务前，用原生确认弹窗展示服务名称、发送的数据种类和用途，以及搜索结果、提取正文将提供给 AI 服务的说明，提供“取消／允许”。允许后记住该服务；取消本次搜索后仍可根据已有资料继续回答。搜索结果和按需读取的网页正文使用原有 Markdown 来源链接。正文读取复用所选服务的密钥与首次授权，不增加独立入口。

### 引用与输入

当前引用完整展示在胶囊输入框上方，长内容在限定高度内滚动。全局 AI 自动取得当前文档背景，不生成文件名引用；只有实际选择的文字或图片显示为待发送引用。输入框与发送按钮排列在同一个胶囊容器内，各自保留独立的原生输入和点击区域。输入框随内容增长，高度上限随可用视口收敛；超出部分在原生输入区内滚动，为回答保留阅读空间。移除按钮独占右侧 44pt 点击区域，与引用标记及首行的中心线对齐；引用的所有行与内容块保持同一右边界，不进入按钮区域。引用标记仅占开头附近的空间，表格、代码等宽块排列在标记下方。长引用滚动时，移除按钮保持在原位。滚动条为细圆角滑块，无可见轨道和箭头，滚动或指针悬停时出现，闲置后淡出。

AI 面板整体避让底部输入界面。停靠软键盘出现时随可用视口调整；底部局部输入浮条出现时，面板底边抬至浮条上方并保留共享间距，引用与输入保持面板内的基础间距，对话区域随面板可用高度收敛，正文和目录仍铺满视口。位置由原生键盘布局指引确定，不按设备或朝向写死偏移。输入浮条收起后面板平滑恢复，连续变化从当前位置衔接；Reduce Motion 下直接更新。

| 引用范围 | 呈现规则 |
| --- | --- |
| 普通选段或单个表格单元格内的选段 | 保留选中内容的富文本，不附加源码行号或一行摘要 |
| 跨单元格选段 | 仅保留选中内容及相对网格位置；边界可保留空单元格，跨行范围按选区裁切，不补入未选中的标题或文字 |
| 完整表格 | 保留表题、合并单元格、对齐与行内格式 |
| 表格前后的选段 | 保持在表格之外，按原顺序排列 |

待发送引用随当前草稿变化，已发送引用保持不可变。用户提问、引用和 AI 回答共用富文本渲染能力，脚注、上标和下标保留各自语义。选区保留所选文字的外层格式和结构；公式与图表按完整语义单元引用，使用原始表达式而非生成的排版文字。已发送引用的折叠预览与展开内容共用富文本渲染，折叠仅限制可见高度；历史恢复遵循同一呈现规则。

预览中轻点图片，使用原生菜单中的“在 AI 对话中引用…”引用该图片；长按和右键保留系统图片菜单及其复制、分享和图片识别能力。带链接的图片保留原有链接跳转。图文混合选段和源码里的完整图片引用也支持视觉输入。选中图片在发送时读取并附带实际画面。全局 AI 先取得全文和图片清单，模型按需读取相关图片，不在每轮发送所有图片。图片地址及替代文本不能替代画面证据；无法读取时如实反馈。

已发送或读过的图片随该文档的 AI 会话保留快照，历史引用、后续追问和重试使用同一份画面。读取范围只包括文档引用的图片：本地文件遵循现有目录授权，网络图片按原地址下载；图片数据不附带原始 EXIF 或位置元数据。首次包含图片的授权不会沿用旧版纯文字发送许可。

软件键盘的回车插入换行，发送按钮提交。实体键盘 Enter 发送、Shift＋Enter 换行；输入法确认与重复按键不会误提交。生成期间可继续编辑下一条草稿，回车保留草稿且不打断生成；收起面板保留会话和生成，停止按钮取消当前生成。

### 请求反馈

处于对话末尾时，回答增长和可用视口高度变化都继续跟随末尾；用户主动向上浏览时暂停，向下实际到达末尾后恢复，仅容忍布局取整的像素误差，不在接近末尾时提前吸附。手动滚动保持连续，布局引发的滚动事件不作为用户操作。自动跟随只补足落后于末尾的距离，系统边界回弹期间不强制拉回滚动位置。

对话滚动区域上方保留一小段固定留白。上方仍有历史内容时，滚动区域的顶部柔和渐隐；回到最顶部时恢复完整显示。渐隐仅作用于对话内容，收起按钮保持清晰和可操作，初始消息的顶部位置不变。

| 状态 | 界面与操作 |
| --- | --- |
| 未配置 | 简洁提示提供取消和设置；成功配置并关闭设置后恢复原入口及引用，等待用户发送 |
| 等待首段 | 在本轮回答起点显示三个依次跃动的圆点，不添加进度或阶段文案；文字到达即呈现，圆点在原处短暂淡出 |
| 生成中 | 增量呈现回答，末尾显示轻量接收标记，提供停止；保持已完成内容和用户手动滚动位置稳定 |
| 完成或停止 | 清除等待与接收反馈，保留已经显示的内容、下一条草稿及已发生的文档修改 |
| 失败 | 在该轮回答内展示简洁原因和手动重试入口，保留草稿、引用与部分回答 |
| 重试 | 仅最新失败轮次可原位重试；收到替代内容后再替换旧回答，已有部分回答时明确表示重新生成 |
| 限流等待 | 等待结束后恢复重试按钮，由用户决定是否重试 |

## 模型设置与系统提示

模型设置以前置原生模态呈现，背景在关闭过渡结束前保持不可交互。连接项包括接口类型、Base URL、API Key 和模型；默认使用 Responses，可明确选择 Chat Completions。

设置页预取模型列表，模型选择页支持本地搜索，并将当前模型独立展示。“自定义”在加载、失败和空结果时均可使用，选择后返回设置并聚焦模型 ID 输入。搜索忽略大小写、空白和 ASCII 连字符，保留版本点号；选择结果始终使用供应商原始 ID。当前选择页的列表快照保持稳定，后台刷新不会在挑选过程中重排项目。

连接配置完整保存在本机钥匙串，恢复后字段完整且地址有效时直接进入 AI；只有配置缺失或无效时提示“尚未配置 AI 模型”。读取失败单独显示错误，不作为未配置处理。设置页在连接项下方单独提供系统破坏性样式的“重置”文字操作；确认弹窗说明将清除连接配置和 API Key，提供取消与重置。确认后立即删除保存值并清空表单，随后取消关闭设置不会恢复旧配置；取消确认不改变任何值。

输入占位文字使用系统占位文字颜色，与已填写的值区分。点击完成时校验实际字段，缺失或无效内容使用原生错误弹窗，直接说明需要修正的字段，不重复页面名称。确认后保留草稿并返回表单，输入过程不弹窗，也不保留独立错误条。读取、保存及重置失败使用相同的原生错误提示；重置操作在确认弹窗关闭完成后执行。

打开文档、本地资源授权和保存失败使用原生提示或系统选择器。资源授权展示实际所需目录，用户在系统选择器中完成授权后继续原操作。保存失败保留当前内容；关闭时提供重试、明确放弃修改并关闭、取消三种选择。

## 文档渲染范围

基础语法由固定版本的 markdown-it 解析，扩展能力按下表维护。正文、引用和对话共用解析与清理流程，针对显示区域采用对应排版。

| 类别 | 支持范围 |
| --- | --- |
| 基础 Markdown | 标题、段落、强调、删除线、引用、列表、分隔线、链接、图片和自动链接识别；强调与删除线采用 CJK 兼容边界规则，支持中文、日文和韩文与标点紧邻的写法 |
| 代码 | 行内代码、围栏及缩进代码块；已识别语言语法高亮，其余保留等宽代码显示 |
| 表格与注释 | Markdown 表格、任务列表、脚注与对应回链 |
| 图片与跳转 | 授权范围内的相对图片和本地 Markdown 链接，包括父目录引用；支持网络图片、文内章节锚点和系统外部链接跳转 |
| 数学公式 | KaTeX 支持的 LaTeX 子集，包含行内及块级公式，依赖随 App 离线打包 |
| 图表 | Mermaid 代码块，使用随 App 打包的引擎并启用严格安全模式 |
| HTML | 经清理的 HTML，包括表格及上、下标等语义元素；脚本、交互表单、内嵌页面和自定义样式被移除 |

宽表格和代码块在自身区域横向滚动，不撑宽正文；图片适应正文宽度。图表或公式解析失败时保留可读的原始内容。标题、目录和跳转目标均来自文档本身；空标题及其目录项按原文保留，不过滤、补名或修正文档内容。

文内章节链接按标题显示文字匹配：字母转小写、空格转连字符、移除标点（保留连字符和下划线），重复目标追加数字后缀。保留 HTML 显式 ID 和脚注目标，解析百分号编码的片段地址；正文与引用内容的内部 ID 隔离，避免跳转到其他呈现区域。

## 动效

| 场景 | 行为 | 参数键 |
| --- | --- | --- |
| 首页进入 | 标志、slogan 和操作从上到下依次向下滑入并渐显；以同一次状态变化启动原生错峰动画，柔和加速后减速，相邻元素保持重叠的运动节奏；同一有序集合决定布局与顺序 | `homeEntrance` |
| 视图切换 | 淡出当前视图，完成目标排版与内容定位后淡入 | `modeOut`、`modeIn` |
| 面板展开 | 保持触发控件位置，转场可被快速反向操作打断并连续衔接 | `layout`、`agentPanel` |
| 文档关闭按钮移位 | 同一个按钮短暂反向蓄力、轻微压缩与倾斜，再向目标位置移动；略微越过后回稳，反向操作从当前姿态衔接 | `documentClose` |
| 输入界面避让 | 跟随系统键盘动画，无动画的浮条布局更新使用可中断的平滑过渡 | `inputAvoidance` |
| 阅读操作展开 | 展开按钮位置固定，独立圆形操作从该处向左滑出并渐显，沿原路收回；chevron 原位连续旋转，快速反向操作从当前进度衔接 | `tools` |
| 等待回答 | 三个圆点错峰上跃、轻落并停顿循环；首段正文到达即退场，不人为延迟回答 | `agentWaiting`、`agentWaitingOut` |
| 引用、回答与修改反馈 | 内容变化局部过渡，保持正文、输入区和用户滚动位置稳定 | `reference`、`message`、`proposal`、`editFeedback` |

自定义动效使用共享参数，系统控件遵循原生转场。开启 Reduce Motion 时直接呈现目标状态，取消位移与装饰动画；等待圆点静态显示，必要的内容定位仍须完成。离开首页取消入场任务，返回时重新播放，新增中央元素通过同一集合参与排序，底部政策入口保持独立。
